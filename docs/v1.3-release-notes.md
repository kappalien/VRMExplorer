# VRM Explorer v1.3.0

- 新增「自定義姿勢」分頁，與動畫／骨骼共用右側位置，維持三欄配置。
- 依軀幹、左右四肢與手指分組選擇骨骼，以 XYZ 滑桿、角度數值或 3D 控制點與旋轉環調整姿勢。
- 支援髖部位移、擷取動畫當前姿勢、單骨骼／整體 T 姿勢重設、復原／重做。
- 切換分頁保留草稿，播放動畫後可恢復編輯；換模型或關閉程式會清除草稿。
- 匯出單幀靜態 VRMA，可重新載入套用；以原生對話框另存新檔，不覆蓋原始素材，不包含表情、模型或貼圖。
- 新功能完整支援繁體中文與英文；更新 README 功能總覽與姿勢編輯展示圖片。

不同身形仍可能穿模；此版本不包含碰撞或 IK。詳見 [姿勢使用說明](v1.3-pose.md)。

## English

Adds the Custom pose tab with grouped bones, XYZ angle inputs, viewport rotation gizmos, hips offsets, animation-frame capture, reset and undo/redo. Drafts survive tab changes and can be resumed after playback; switching avatars or exiting clears them. Export a static VRMA as a new file without avatar geometry, textures or expressions. Traditional Chinese and English are supported. Collision and IK are outside this release.
