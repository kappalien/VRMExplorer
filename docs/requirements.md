# Requirements

產品與階段要求以根目錄規格為準。這次範圍僅 Phase 0；Phase 1–6 沒有實作。

Phase 0 包含桌面初始化、严格 TypeScript、Lint/Format、Vitest、可調整版面、i18n、Theme、PortablePathService、內建 Plugin API 與離線可行性評估。

Phase 0 基本驗收已完成：Rust 測試/格式/Clippy、Windows x64 除錯版建置與實際啟動、語言/深色切換、Splitter 互動、設定重啟與根目錄搬移。DPI、無 WebView2 Runtime、Fixed Runtime Offline 與乾淨機仍未驗證；不得當作正式 Portable 發行版本。依規格停在 Phase 0。
