# 產品需求

目前產品與技術要求以根目錄 [VRM Explorer 開發規格](../VRM_Explorer_Development_Spec.md) 為準，涵蓋檔案瀏覽、多模型場景、PNG 匯出、VRMA 播放、自定義姿勢、骨骼檢視、背景縮圖、Portable 設定、簽章更新及 MIT 授權。

目前功能與操作入口見 [繁體中文 README](../README.md)／[English README](../README.en.md)。歷史階段及驗證文件保留作為當時紀錄，不代表目前功能範圍；版本更新紀錄見 [GitHub Releases](https://github.com/kappalien/VRMExplorer/releases)。
