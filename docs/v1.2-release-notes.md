# VRM Explorer v1.2 Offline — Windows x64

新增骨骼檢視，精簡設定頁與擴充架構；保留 v1.1 的模型預覽、圖片瀏覽、動畫素材庫、單幀姿勢、表情、檢視偏好與 Portable 資料保存功能。

## v1.2 更新

- 預覽區新增「骨骼疊加」勾選，與格線、座標軸選項並列；骨架可跟隨模型動畫顯示，預設關閉。
- 動畫區新增「動畫／骨骼」分頁，沿用原有位置與三欄版面，切換分頁保留動畫狀態。
- 骨骼分頁列出標準人形骨骼、原始模型節點、父節點及必要／選用狀態，提示缺少必要映射；依 VRM 0.x／1.0 區分 chest、neck 的要求。
- 移除自訂 Plugin 架構、範例命令與外部擴充提示；系統資訊與縮圖快取管理保留為一般設定功能，既有 Plugin 資料不刪除。
- 設定頁不再顯示 Portable 資料路徑，改顯示應用程式版本與 WebView2 執行環境模式。
- 修正開發啟動位址不一致，統一使用本機 127.0.0.1。
- 新增介面文字完整提供繁體中文與英文。

骨骼資訊為唯讀映射檢視，並非完整蒙皮、階層或姿勢驗證。尚未新增模型快照縮圖或 GLB／FBX／BVH 轉換功能。

## 使用與升級

下載 Offline ZIP，完整解壓後開啟 `vrm-explorer.exe`；不需安裝 Rust、Node.js 或 MSVC。GitHub 自動產生的 Source code ZIP 是原始碼。Windows 11 x64，隨附 Microsoft Fixed WebView2 Runtime 154.0.4258.62。

升級前關閉程式並備份原有 `data/`。使用新包內的 `upgrade.ps1` 更新程式，保留設定、索引與快取。舊版可攜下載由 v1.2 取代，歷史功能及授權說明保留。

使用前請閱讀包內 `licenses/Microsoft-WebView2-Fixed.html` 與 `docs/portable-release.md` 的條款及隱私聲明。包內包含第三方授權及 5 個未修改 MPL 元件原始碼封存；原始素材唯讀，VRM／VRMA 模型、動畫、資料庫及個人設定均不隨包提供。

完整操作說明：[README](https://github.com/kappalien/VRMExplorer#readme)；[授權與署名](https://github.com/kappalien/VRMExplorer/blob/main/docs/licensing.md)。

## English

v1.2 adds a skeleton overlay and a Bones tab beside Animation, showing raw humanoid mappings, parent nodes and required-bone status. It preserves the three-pane layout and animation state. Custom plugin support is removed while system information and cache management remain. Settings now shows the application version and WebView2 mode instead of the Portable data path. Traditional Chinese and English are supported.

Extract the Offline ZIP and run `vrm-explorer.exe`. Back up `data/` before upgrading. Fixed WebView2 is included, together with third-party notices and MPL source archives. No user models, animations or personal data are distributed.
