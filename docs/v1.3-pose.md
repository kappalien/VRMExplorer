# v1.3 自定義姿勢

此階段新增姿勢編輯與靜態 VRMA 另存，不改原始素材。版本使用 1.3.0：屬於新增相容功能，保留既有資料格式及 Portable 流程。

1. 開啟 VRM，在右側選「自定義姿勢」，按「繼續編輯」。初次操作使用目前畫面姿勢。
2. 播放／暫停動畫後可用「擷取目前姿勢」建立草稿，編輯會暫停播放。
3. 選擇骨骼群組中的骨骼，以 XYZ 角度滑桿／數值調整，或點畫面控制點並拖曳旋轉環。拖旋轉環時攝影機不會跟著旋轉。手指依模型實際映射顯示；眼球不屬於此階段的骨骼操作。
4. 髖部支援相對 T 姿勢的 XYZ 位移（公尺）；其他骨骼僅能旋轉，避免破壞骨架長度。
5. 可重設單骨骼／整體 T 姿勢及復原／重做，最多保留 80 次操作。滑桿放開或數值欄位離開時記錄操作。
6. 「匯出靜態 VRMA」開啟 Windows 儲存對話框，請使用新的 `.vrma` 檔名。取消不寫檔；既有檔案不覆蓋。
7. 匯出檔可放入動畫來源再掃描，或透過檔案瀏覽選擇，按「套用姿勢」使用。

切換分頁保留草稿，播放／停止／拖曳動畫時間軸會退出手動編輯，可再按「繼續編輯」恢復草稿。換模型或結束程式清除草稿；尚無草稿磁碟保存。

匯出採 VRMC_vrm_animation 1.0、GLB 二進位封裝及時間 0 的單鍵影格。只包含 normalized humanoid 骨骼旋轉、髖部位移與綁定所需 T 姿勢節點。VRM 0.x 轉為規範座標方向。沒有網格、貼圖、材質、表情、視線或 Spring Bone 模擬結果。不同模型的身形與肢體長度仍會導致手掌穿越，此編輯器不含 IK、碰撞或自動接觸求解。

匯出由 Rust 開啟原生對話框並寫檔，檢查容器大小、路徑、副檔名及連結，以同資料夾暫存檔配合不覆寫的原子發布保存。前端不直接存取檔案系統。編輯器及控制點只在首次編輯後建立，使用既有 renderer，沒有背景掃描或全清單快照。

## API 核對

- [Three.js TransformControls](https://threejs.org/docs/pages/TransformControls.html)
- [pixiv VRMHumanoid](https://pixiv.github.io/three-vrm/docs/classes/three-vrm.VRMHumanoid.html)
- [VRMC_vrm_animation 官方規格](https://github.com/vrm-c/vrm-specification/tree/master/specification/VRMC_vrm_animation-1.0)
- [Tauri 原生檔案對話框實作](https://github.com/tauri-apps/plugins-workspace/blob/v2/plugins/dialog/src/lib.rs)，並核對本地 2.8.1 API

調整模式參照 [tk256ailab/vrm-viewer](https://github.com/tk256ailab/vrm-viewer) 的骨骼分組、角度與旋轉環操作；此處獨立實作，不載入該專案的 CDN 程式碼。
