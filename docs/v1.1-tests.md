# v1.1 驗證 / Validation

版本 1.1.0、畫面 v1.1，只提供 Offline win-x64。沿用 Microsoft Fixed WebView2 Runtime 154.0.4258.62。

## 修正

- 原先拒絕 duration <= 0 的判斷，改為接受 duration == 0 且含有效軌道的單幀 VRMA。單幀使用 LoopOnce、time 0 與暫停動作保持姿勢，避免循環時除以 0。介面啟用「套用姿勢」，停用不適用的時間軸、速度／循環控制，不捏造動畫長度。
- 不再因模型缺少可選骨骼而拒絕所有綁定，交由官方 createVRMAnimationClip 略過不存在的目標；完全沒有可用軌道的素材仍拒絕。
- Rust 的動畫紀錄接受有限且非負 duration；負數／NaN 仍拒絕。
- 左側工具列加回小圖示切換精簡清單／縮圖，沿用 Portable 檢視偏好；固定工具列欄位，避免增加控制區或因語言／圖示換行。

API 核對 Three.js：https://threejs.org/docs/pages/AnimationAction.html ；pixiv：https://pixiv.github.io/three-vrm/docs/functions/three-vrm-animation.createVRMAnimationClip.html 。

## 已執行

- Vitest 23 項通過。實際 Three AnimationMixer 骨骼權重驗證單幀套用、保持、停止、再次套用、缺少可選骨骼及切回動態播放；空軌道仍拒絕。
- Rust 17 項通過，含零長度紀錄保存；clippy all-targets 通過。
- Edge 4 項通過：位置與設定還原／小圖示切換及高度不變／檢視偏好保存；50,000 項列表；Vivian VRM0 真實 loader／WebGL／表情；完整 App 配合 IPC mock 與真實 VRM／VRMA loader，單幀姿勢及動態播放切換。
- 單幀測試在瀏覽器記憶體中將 Test.vrma 衍生為一個 time-0 keyframe 並指定左手臂旋轉；未修改原始檔，測試／模型均不進入發行包。使用者反映的特定靜態檔案未提供辨識路徑，該檔案：Not Tested。
