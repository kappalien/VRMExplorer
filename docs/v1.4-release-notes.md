# VRM Explorer v1.4.1

- 設定頁新增「線上更新」，一鍵完成檢查新版、下載、簽章驗證、替換及重新啟動。
- 使用 GitHub Release、Ed25519 簽章更新資訊及獨立 Rust 更新器。
- 獨立程式更新包約 7.2 MiB；WebView2 版本未變動時不重複下載 Runtime，版本不同時下載獨立 Runtime 包。
- 提供下載進度、取消與可選的啟動後檢查新版；背景檢查不會自動安裝。
- 保留 Portable 設定、索引、快取與個人資料；更新前提醒目前姿勢草稿，啟動失敗會嘗試還原並啟動舊版。
- 修復檔案檢視切換無法返回「詳細資訊」的問題，支援詳細資訊、縮圖與精簡檢視循環切換；詳細資訊顯示檔案類型、大小與修改時間。
- 更新介面完整支援繁體中文與英文，保留原有三欄配置與展示圖片。

首次使用或從 v1.3 升級，請下載完整 Offline 可攜包。v1.4 起可在「設定 → 線上更新」使用一鍵更新；後續版本需提供對應簽章資產。更新包不包含 VRM／VRMA 素材或個人 data。詳見 [更新說明](v1.4-updates.md)。

## English

Adds one-click online updates through GitHub Releases, signed Ed25519 metadata and a standalone Rust updater. Routine app updates are about 7.2 MiB and exclude unchanged WebView2. Includes download progress, cancellation, optional startup checks, pose-draft reminders, preserved Portable data and rollback on startup failure. Restores the Details view in the Details → Thumbnails → Compact cycle, including file types, sizes and modification times. Traditional Chinese and English are supported. Users upgrading from v1.3 need the full Offline package once.
