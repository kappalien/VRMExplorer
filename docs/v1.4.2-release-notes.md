# VRM Explorer v1.4.2

- 檔案清單隨視窗高度填滿可用空間，項目數固定在面板底部，放大視窗可顯示更多檔案。
- 骨骼對應表填滿骨骼分頁剩餘空間，移除固定高度限制，隨視窗尺寸自動伸縮。
- 記住關閉時的視窗大小與最大化狀態，下次啟動自動還原；最小化不覆寫一般大小。不同 DPI 或螢幕尺寸時，還原大小會限制於目前螢幕可用範圍。
- 視窗設定保存在 Portable 的 `data/settings/window.json`，設定、索引、快取及原始素材保持完整。
- 本版本只提供小型程式更新包與簽章資訊，不提供新的完整可攜包。首次使用請下載 v1.4.1 完整可攜版，再透過「設定 → 線上更新 → 一鍵更新」升級。

v1.4.0 與 v1.4.1 可直接更新至 v1.4.2，不必逐版安裝；本次 WebView2 版本未變動，因此不需下載 Runtime。

## English

File browsing and the bone mapping table now fill the available panel height and resize with the window. The app remembers its normal window size and maximized state, preserves them when minimized, and restores them within the current monitor's available area. State is stored in Portable data. This release contains only the signed app update package; new users can download the full v1.4.1 Portable package and update in Settings. Both v1.4.0 and v1.4.1 can upgrade directly to v1.4.2 without downloading the unchanged WebView2 Runtime.
